Sequence

Presets have the initiator Met removed, so H3 K4 is residue 4. If your sequence starts with M, set the first residue # to 0.

Detected peptides Example data

One proteoform per line — each line gets its own underline, with its modifications drawn on that line. Put modifications in brackets after the residue: TK[me3]QTAR, K[ac]STGGK[ac]APR. Mass shifts work too: K[+42.011]. Use @9 to fix the start position, or a range like 9-17. Lines starting with # are ignored.

Extra modification sites

Sites not tied to a peptide above, e.g. K27me3, K36me2. Use Ntac (or Nt-ac) for the protein N-terminus and Ct… for the C-terminus. Separate entries with commas; put marks found together in one entry, separated by spaces, for a combinatorial proteoform: K8ac M54ox. Clicking a residue in the figure edits this list.

Proteoform matrix

One row per line in Detected peptides, plus one row per extra modification site; one column per modified site. Black dots are sites detected unmodified; coloured dots show the mark carried by that proteoform. Write N-terminal marks before the first residue: [ac]-S[ph]GRGK…
